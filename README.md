# Firstgear PDF Converter

Converteer voertuig-PDFs automatisch naar gestandaardiseerde TXT-optielijsten.

## Features

✅ **Drag & Drop PDF Upload** - Simpel interface
✅ **Automatische Type Detectie** - VWE, Factory Info, Range Rover
✅ **Instant TXT Download** - Klaar voor website
✅ **Ondersteunt alle merken** - BMW, Mercedes, Porsche, Audi, Land Rover

## Quick Start

### 1. Deploy op Vercel (5 minuten)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fyourname%2Ffirstgear-pdf-converter&project-name=firstgear-pdf-converter&repo-name=firstgear-pdf-converter)

### 2. Of lokaal runnen

```bash
# Clone repository
git clone https://github.com/yourname/firstgear-pdf-converter.git
cd firstgear-pdf-converter

# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Hoe gebruiken
